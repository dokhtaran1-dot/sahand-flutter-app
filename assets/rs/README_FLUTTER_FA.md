# جعفر درگاهی — Beyond Gravity

بستهٔ محلی برای افزودن صفحهٔ جعفر درگاهی به Royal One از مسیر RS. فایل `index.html` نقطهٔ ورود است. HTML، CSS و JavaScript صفحه یک‌جا قرار دارند؛ تصاویر، داده‌ها، نشان‌ها و فونت‌های Vazirmatn، Manrope و Cormorant Garamond کنار آن بسته‌بندی شده‌اند.

## استفاده در اپ Flutter

1. پوشهٔ این بسته را با نامی مانند `assets/jafar_dargahi/` در پروژهٔ Flutter کپی کنید.
2. مسیر پوشه را در بخش `assets` فایل `pubspec.yaml` ثبت کنید.
3. فایل `index.html` را از داخل WebView اپ با مسیر asset محلی باز کنید.
4. لینک‌های سفارش واتساپ در محیط دارای واتساپ و اینترنت باز می‌شوند؛ بقیهٔ صفحه و رسانه‌هایش از فایل‌های همین بسته بارگذاری می‌شوند.

مسیرهای تصاویر و فونت‌ها نسبت به `index.html` هستند و هیچ فونتی از Google Fonts درخواست نمی‌شود. افکت بخار ملایم و درخشش چراغ داخل CSS موجود است.
